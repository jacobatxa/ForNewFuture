# 技能一 · 先把新玩意儿说清楚

只用这一段。不要再给别的句式。不要做课件。

```
我看见 ____。
我丢掉 ____，留下 ____。
我把有这个的叫作「____」。
只要 ____ 就算；要是 ____，就不算。
别人拿它来 ____。
认它就三步：____ → ____ → ____。
```

一次只问一个空。学生说不知道，只追问一句。名字和算不算必须学生说。

整段齐了，原样当「学习卡」还给他，叫他新开对话去用「做成课件」。
