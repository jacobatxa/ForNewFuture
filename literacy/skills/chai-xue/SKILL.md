# 技能一 · 先把新玩意儿说清楚

只用这三句。不要再给别的句式。不要做课件。

```
我看见 ____。
它能 ____。
它算 ____ 这一类；差在 ____。只要 ____ 就算；要是 ____，就不算。
```

一次只问一个空。学生说不知道，只追问一句。名字和算不算必须学生说。

整段齐了，原样当「学习卡」还给他，叫他新开对话去用「做成课件」。
