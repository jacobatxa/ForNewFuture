# 技能二 · 做成课件

开工前学习卡六行必须齐。缺一行，一次只问一个空，不要做页。

- 一页只讲「底下」那三步。
- 画零件，不画方块箭头。编号，写是什么、干什么。
- 命名句、边界句写在页上。
- 做完列两处可能不对。
- 先用 3 行说你要做什么，等点头。能写网页就给单文件 HTML。
