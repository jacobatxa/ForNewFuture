# 技能二 · 做成课件

开工前学习卡三句必须齐。缺一句，一次只问一个空，不要做页。

- 一页只讲看见的那几块，和它能干什么。
- 画看见的那几块，不画方块箭头。编号，写是什么、干什么。
- 「算哪一类」和「算不算」写在页上。
- 做完列两处可能不对。
- 先用 3 行说你要做什么，等点头。能写网页就给单文件 HTML。
