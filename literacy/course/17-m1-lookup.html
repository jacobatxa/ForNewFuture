01AI 的设计，是对人的功能做抽象

这一块回答：科学家造 AI，是把人办事的步骤抽出来，舍掉血肉，留下能装进机器的功能，再给功能起名。

人身上的本事

  • 看 · 听 · 摸
  • 还能想起什么
  • 想下一步
  • 说 · 做
  • 临时多一样本事
抽
→
装

机器上的零件

  • 输入 摄像头、键盘、麦、提示词
  • 记忆 参数，或关于你的记录
  • 分析 猜下一个最可能的词
  • 输出 字、声、图、动作
  • 技能 可装卸的 Skill

02抽完之后，市场上分成三格，零件各有名字

这一块回答：你打开的「AI」是哪一格；提示词、记忆、Token、技能分别卡在 01 的哪个零件上。先有 01，这些词才对得上。

三格 · 按用途认谁在用，怎么用

大模型打开聊天 → 说清楚 → 看回答。豆包 / DeepSeek / ChatGPT
运行环境打开项目 → 指文件 → 让它改。Cursor / Claude Code / Codex。别叫编程工具
个人助手定目标 → 装记忆和技能 → 它去办。豆包工作台 / 飞书 / Hermes

零件上的词都回到 01 那五格

提示词就是输入。你说不清，它就猜
记忆两层：模型里的参数；助手里关于你的记录
Token读写用的小块，常按块计费
技能可拔插。拔掉了，模型还会聊天
「想」不是理解人生，是猜下一个词

03你要学会同一套抽象，拿去解决问题

这一块才是带走的本事。01 和 02 是别人已经抽好的例子。这里换成你来抽：猛禽、自行车、书包，都可以。

舍丢掉跟这一类无关的差别
取留下共同的那一点
命给共同点起名字
验拿一个边界例子问：算不算

命名：我把「___」的共同点命名为「___」。
边界：凡是 ___ 都属于 ___；只要 ___，就不算 ___。
