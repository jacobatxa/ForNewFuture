03三格货架 · 按用途认

先问：谁在用？怎么用？名字不重要。

01大模型 · Model谁：几乎人人　怎么用：打开聊 → 说清楚 → 看回答
例：豆包 / DeepSeek / ChatGPT
02运行环境 · Runtime谁：要交作品、改网页　怎么用：打开项目 → 指文件 → 让它改
例：Cursor / Claude Code / Codex　（别叫「编程工具」）
03Personal Agent · 助手谁：要长期办事　怎么用：定目标 → 装记忆/技能 → 它去办
例：豆包工作台 / 飞书 / Hermes
