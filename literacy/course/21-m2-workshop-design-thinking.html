01
EMPATHIZE

共情 · 现场勘查

任务：分清事实与猜测

本案进展：小侦探没有急着买新杯子，而是跟着小林过了一天，记下他喝水、塞书包的每个动作——先拿到事实，再谈判断。

跟着小林学 DEMO

他在笔记本上写：我观察到小林在「课间换教室」时，「把杯子横着塞进侧袋」，杯口正对着书本；我好奇为什么他不把杯子立着放？——注意，全程只写看到的，不写「他真邋遢」这类猜测。

SCRIPT · 照着说的句子
TASK小测验：点每张卡片，判定它是「事实」还是「猜测」，再点核对
填完四个空并判定全对，即可盖章
02
DEFINE

定义 · 锁定真问题

任务：写出 POV 问题陈述

本案进展：线索拼起来了：杯盖不是自己松的，是被侧袋里的书本一路顶开。要解决的不是「买杯子」，而是「挤压下杯盖松动」。

跟着小林学 DEMO

用户（走读生小林）需要（杯盖在书本挤压下保持锁紧），因为（书本挤压会顶开杯盖、泡湿书本）。
HMW，我们可以怎样让杯盖在侧袋里不被顶开？——句子里没有出现任何具体方案。

SCRIPT · POV 句式
TASK选出合格的问题陈述（POV），点一下看反馈
填完四个空并选对 POV
03
IDEATE

构思 · 线索风暴

任务：先求数量，再做判断

本案进展：侦探们贴了一墙点子：硬托、绑带、吸盘杯套……越怪越要留下。这一轮只有一个纪律——谁都不许说「不可能」。

跟着小林学 DEMO

有人说「给侧袋加个硬托」，下一个人接住：「Yes, and……对，而且还可以让硬托带个绑带，连水杯一起固定。」先攒够 20 个，再用贴纸投票选出主攻线索。

轮到你办自己的案 YOU

SCRIPT · 接句式
TASK头脑风暴纪律判断：这些话合规吗？（✓ 合规 / ✗ 违规）
写满 3 个点子并判断全对
04
PROTOTYPE

原型 · 做出证物

任务：用最低成本验证一个假设

本案进展：不开模、不等工厂。卡纸、海绵、橡皮筋，20 分钟拼出一个能塞进侧袋的硬托——它丑没关系，能验证假设就行。

跟着小林学 DEMO

这一版只验证一个假设：侧袋加硬托，杯盖就不会被顶开。最便宜的做法：用废卡纸折一个硬托，0 元、20 分钟。至于好不好看、能不能量产，那是以后的事。

轮到你办自己的案 YOU

SCRIPT · 原型假设句
TASK勾选你的原型材料：目标「总成本 ≤ 10 元、当天能做完」
预计总成本：0 元 达标：便宜、当天能试——这是原型，不是成品。 太贵或太慢：原型要当天就能上手，去掉重型方案。
填完两个空并凑出达标方案
05
TEST

测试 · 用户验证

任务：只观察、只追问，不诱导

本案进展：硬托交给小林用一周。他取杯子时卡了一下——小侦探没有辩解，只把这个停顿记下来，它就是下一版要改的线索。

跟着小林学 DEMO

全程让用户自己操作，小侦探只问开放式问题：「刚才这里发生了什么？哪一步让你停顿了？」绝不说「你是不是挺喜欢的？」——那是在逼用户配合你。

轮到你办自己的案 YOU

SCRIPT · 只问不辩

填完两个空并辨别全对
