三句话，
把一个东西说完

01
它长什么样什么颜色、什么形状、大还是小。声音、气味、手感，只要能观察到的都算。这一句先不要说出它的名字。
02
它能干什么它自己会做什么？别人拿它派什么用场？
03
它算哪一类先说出一个判据，再说清按这个判据它算不算，最后举一个「不算」的例子。

顺序不能换。第一句只描述、不报名字；第三句必须你自己下结论。

AI 可以帮你画，可以帮你排版，但它不能替你回答「算不算」。

讲完，
把它拿出来给大家看

1
形式随你一张图、一个链接、一段屏幕录制，都行。能投屏、能看清就可以。
2
打开的时候说两句话这一页里哪一句是我自己写的；哪一处我怀疑是 AI 编的。
3
说完停下来听我点评的时候只问三件事：少了哪一句、判据站不站得住、有没有举出反例。

这一轮没有对错，只看三句话齐不齐。缺哪一句，我指出来，你当场补。

01 它长什么样
在显微镜下是圆圆的一小团，中间有一个颜色更深的点，外面还有一圈边。

它算细胞——组成身体的最小单位。我先把判据写成：有细胞膜、有细胞质、有细胞核，就算细胞。病毒三样都没有，所以不算。

先别急着记住这条判据。下一页我们就用它去撞一个例外：细菌没有成形的细胞核，那它还算不算细胞？

三段论：
判断一个东西，只要三步

苏格拉底一辈子都在追问「凭什么」。追到底，就是把一句大前提逼出来。有了它，「算不算」就不用猜，照着走三步。

第一步 · 大前提凡是 ______ 的，都算 ______。这句是定义，写歪了后面全错
第二步 · 小前提这个东西 ______。拿它去对大前提，一条一条对
第三步 · 结论所以它 ______。不是「我觉得」，是被前两句逼出来的
苏格拉底会死凡是人都会死 → 苏格拉底是人 → 苏格拉底会死。最经典的一条，两千多年了还在用
鲸是哺乳动物凡是胎生、喝妈妈奶长大的，都是哺乳动物 → 鲸胎生、喝奶 → 鲸是哺乳动物。
企鹅有羽毛凡是鸟都有羽毛 → 企鹅是鸟 → 企鹅有羽毛。企鹅不会飞，但有羽毛——所以它是鸟
铜导电凡是金属都导电 → 铜是金属 → 铜导电。
蝙蝠不是鸟凡是鸟都有羽毛 → 蝙蝠没有羽毛 → 蝙蝠不是鸟。只推出了「不是鸟」。要说它是哺乳动物，得换一条大前提重推
蜘蛛不是昆虫凡是昆虫都有六条腿 → 蜘蛛有八条腿 → 蜘蛛不是昆虫。

同一个东西，换一条大前提，结论就可能变。所以第一步写着定义，也是最该被怀疑的一句。

拿病毒练一遍：
大前提被撞歪，就改它

上一页我写的是「有细胞膜、有细胞质、有细胞核，就算细胞」。现在拿细菌和病毒来撞它一下。

第一步 · 大前提（先这么写）
凡是有细胞膜、有细胞质、有细胞核的，都算细胞。
撞一下 · 细菌
细菌没有成形的细胞核，可它明明算细胞。所以「有细胞核」这一条太严了，得改成：有细胞膜、有细胞质、有遗传物质，并且能自己完成生命活动。
第二步 · 小前提
病毒只有一层蛋白质外壳包着一段遗传物质。它没有细胞膜，也不能自己完成生命活动，只能钻进别的细胞里才能复制。
第三步 · 结论
所以，病毒不算细胞。

结论不是「我觉得」，而是上面两句一起逼出来的。换个同学来推，也只能推到这儿。

大前提写歪了，后面推得再顺也是错的。这就是为什么最后要写下「两处可能不对」——先怀疑的应该是最上面那句。

林奈：
给每个东西安排一个格子

快三百年前，瑞典人林奈干了一件笨事：把当时知道的生物一种一种排进七个格子，再给每种生物起一个两段式的拉丁名字。到今天，全世界还在用他这套。

界Animalia 动物界
门Chordata 脊索动物门
纲Mammalia 哺乳纲
目Primates 灵长目
科Hominidae 人科
属Homo 人属
种Homo sapiens 智人

格子一层比一层窄：往下走一步，能装进去的东西就少一批；走到最底下，只剩它自己。Homo 是属名，sapiens 是种加词，两个词合起来才是这个物种的名字。

三段论管「这一个东西算不算」，林奈管「一大片东西怎么排」。第三句话两个都要用：先说出判据，再找到它该进的格子。

标本 02 · 猛禽发动机

换个东西，
说法一个字都不换

用 anatomy 做的拆解示意，不是 SpaceX 的工程图纸
01 它长什么样
上面挤着两台涡轮泵和一圈管路，中间是主燃烧室，下面接着一只上细下粗的钟形喷管。
02 它能干什么
液氧和液甲烷各自先加压，送进主燃烧室烧掉，燃气从喷管高速喷出来，把火箭往天上推。
03 它算哪一类
判据：自己能加压、自己烧、自己把燃气喷出去的，算火箭发动机。飞机发动机要吸外面的空气才能烧，所以不算。

中文里「猛禽」本来指老鹰那一类鸟。同一个词，在这儿指的是一台机器——名字跟类别没有必然关系，得看判据。

提示词：
一张卡，五个空

「新玩意儿」是个很大的筐：一个物体、一个概念、一首诗、一条公式，都能往里装。这张卡不变，每次只换第二个空。

01
让它当谁「你是我的讲解员，不是百科全书。我正在学一个我还不懂的东西。」
02
给它材料（每次只换这里）「我要学的是：______。」填一个词、一张图，或者一段原文。
03
让它按三句来答「先说外表，不许报名字；再说它能干什么；最后给我一条判据、一个不算的反例。判据对不对，我自己定。」
04
给它四条规矩「一次只问一个空；用我听得懂的话说；我没填的空你别替我填；你不确定的地方要标出来。」
05
要它交什么「输出一页，三条编号，末尾写下两处你可能说错的地方。」

五个空里，只有第 02 个每次换，其余四个永远照抄。

不填这张卡，只说一句「介绍一下细胞」，它会给你发现史、人名、十页提纲——那不是你要的。

同一张卡，
换四种东西试试

第二个空换掉，第三句跟着变形，但仍然是三句。

物体 · 猛禽发动机第三句：只要自己能加压、自己烧、自己把燃气喷出去，就算火箭发动机。飞机发动机要吸空气才能烧，不算。
概念 · 潮汐第三句：海水因为月亮和太阳的引力，一天里规律地涨落，这算潮汐。地震掀起的海浪没有这种规律，不算。
诗 · 静夜思第一句改成「我读到」：四句，每句五个字，写床前的月光像霜。
第三句：它算思乡诗——写月亮的诗很多，只有最后落到「低头思故乡」的，才算这一类。
公式 · a² + b² = c²第一句改成「它长什么样」：一行等式，三个字母，两个字母右上角有个小 2。
第三句：三条边满足 a² + b² = c² 的三角形，就是直角三角形。边长 3、4、6 不满足（9 + 16 ≠ 36），所以不是。

句式可以跟着东西变，顺序不能变：先长什么样，再能干什么，最后才是算不算。

技能：
一份提前写好的说明书

你每次都要重复那四条规矩，很累。有人把这些规矩写成一份文件——这就是技能。用之前把这份说明贴进去，它就知道该怎么配合你。

技能一问的时候用

一次只问一个空。三句话没说完，不许它画图，不许它替你起名字。

技能二做图的时候用

只做一页。膜、质、核要编号，「算不算」那句必须写在页面上。

两份现成的我发给你们

今天不用你自己去写，也不用去 GitHub 找。我把这两份整理成纯文字，课后发到群里，你们复制就能用。

不贴说明书，只说「帮我做个课件」，它会给你做成一页百科。

以后想找别人写好的，可以去 GitHub 搜 skills——那是给有基础的人逛的仓库，今天我们先用现成的。

说明书和图，
怎么交给它

1
说明书：整段粘进对话最稳把那份文字复制，粘在对话框最前面，后面再加一句：「按这份说明书的规矩来回答我。」
2
也可以上传文件点输入框左边的回形针（有的版本是一个「+」）。图片、课本那一页、说明书文件都能传。
3
别只丢文件、一个字不打它不知道你要它干什么，就会自己编一套。传完一定要补一句：这份文件是什么、你要它用这份文件做什么。
两个必须知道的限制：

一、说明书的效力只在这一轮对话里。开一个新对话，它就不记得了，得重新贴一遍。

二、传了图之后，先让它复述一句：「这张图里有几个格子？是一个细胞，还是很多个？」它复述对了，再往下问。

它会编，
而且编得很像

左边是常见的「AI 做的一页」：版式漂亮，图是随手画的，字都对。看着没问题。右边是刚才那张真图，两张摆在一起对。

三样东西，
不要交出去

1
你的真名、学校、住址、密码聊天框不是日记本。要举例就用「我们班有个同学」，不要写具体是谁。
2
别人的脸和照片没有对方同意，不要上传。给自己家人拍照也是一样，先问一句。
3
「它写完，你直接交」这条路三句话必须是你的。它只负责把你说的做成能看的一页。交上去的东西你得能自己讲一遍。

能被AI替你做的是「排版和画图」，不能替你做的是「判断」。

把一个东西拆到底

今天你学会的是「用一个说法讲清一个东西」。下节课反过来：把一个看起来很简单的东西拆开，看看里面到底有几层。
