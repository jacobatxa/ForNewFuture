03 会提问 · What Is a Prompt

Prompt，就是你对 AI 说的话 A Prompt Is What You Tell It

AI 很能干，但它猜不到你心里想什么。
你说得越清楚，它办得越好。这几句话，就叫 Prompt。

Prompt 含糊

「帮我带个吃的。」

结果：带回来一包辣条，可你不吃辣。

Prompt 清楚

「帮我从食堂二楼带一份不辣的面，12:10 前送到教室。没有面就先发消息问我。」

结果：正好是你想要的。

记住Prompt 写清楚，事情才办得对
03 上下文 · What Is Context

AI 只知道你告诉它的 Context Is Everything It Sees

它没眼睛，看不见你们教室；它没来过你们学校，也不认识你。
当前对话里出现的话，就是它的整个世界。这一堆话，叫上下文。

01 它没来过你们学校

所以会一本正经说「门口有 17 棵香樟树」。它不是记得，是在猜。

02 前面的词，决定后面的词

「我口渴了，想喝一杯__」和「我在咖啡店，困了，想喝一杯__」，答案会不一样。

03 关掉窗口，世界就没了

普通聊天一关就忘。Agent 的「记忆」，就是把重要上下文写进小本子。

记住你多告诉它一点，它就聪明一点
03 写好 Prompt · 5 Good Habits

写好 Prompt 的五个习惯 Goal · Context · Options · Decide · Check

01说清目标

说你想要什么结果，不用一步步教它怎么做

02给足 Context

你是谁、在哪里、已经试过什么——它只知道你告诉它的

03让它多想几种办法

请它给出 2 到 3 种不同的方法，说说好处和难处

04你来做决定

你选一种，说清楚为什么，再让它接着做

05对照目标检查

办成了吗？不确定的地方，让它说「不知道」

网上很多技巧教你背模板、写「你是一个专家」。我们更看重：目标清楚、Context 够、决定在你。

04 什么是 Agent · From Chat to Agent

会聊天的 AI，和会办事的 Agent Chatbot vs Agent

普通聊天

像一本会说话的百科全书

  • 你问一句，它答一句
  • 关掉窗口，就忘了你
  • 只会说，不会去做
Agent

像你请来的一个小助手

  • 交代一件事，它一直做到办完
  • 记得你之前说过什么
  • 会用工具：查资料、发消息
记住聊天一关就忘；Agent 把上下文记在小本子上，把事办完

04 Agent 怎么干活 · How an Agent Works

从接到任务，到把事办完 Task In → Result Out

01
接到任务

读懂你的 Prompt：要办成什么、有什么限制。

例：小明说「我丢了蓝色水壶，最后在图书馆三楼见过。」
02
翻翻记忆

在 Context / 小本子里找：以前有没有相关记录。

例：有没有人登记过「捡到蓝色水壶」？
03
想出下一步

大脑规划：现在该查表、该通知，还是先问清楚。

例：对上了 → 通知两边；对不上 → 先记下来，不编。
04
调用工具去做

真正动手：写进登记、比对、发消息、查网页……

例：把失物写入记忆；匹配成功就各发一条通知。
05
交回结果，等人检查

把结果给你看。没办完就回到第 3 步继续；不确定就说不知道。

例：「疑似对上了，请两边自己确认是不是同一件。」
Agent 常干的活

不是只会聊天

  • 查网页、课表、登记表
  • 记把 Context 写进记忆
  • 写通知、总结、草稿
  • 发群消息、提醒
  • 比失物对号、表格核对
  • 跟没办完就继续盯
  • 问缺 Context 先问你

关键差别：普通聊天停在「说」；Agent 会「记 + 做 + 回报」。

04 Agent 做网页 · Build a Web App with Agents

校园寻物：Agent 做出的网页应用 From Prompt to Browser

01
说清你要什么网页

用 Prompt 讲清楚：谁用、干什么、长什么样、不能乱编。

「做一个校园寻物网页：左边登记丢失，右边登记捡到，能对上号。」
02
让 Agent 写代码

它会生成 HTML / CSS / JS。你不用先会编程，但要看得懂页面在干什么。

03
在浏览器里打开试

拖进 Chrome / Safari，点一点。哪里不对？截图或描述给 Agent。

04
再说一遍，让它改

「按钮再大一点」「对不上要说不知道」。Agent 改完，你再试——这就是做产品。
