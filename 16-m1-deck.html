M1 · Myth

It is not “thinking.” It is next-token prediction.

Cut it open: context in, most-likely next token out, then the next, until it stops. Sounds like an answer. Underneath: prediction.

What you seeFluent text that sounds like a reply
What the machine doesGiven prior tokens, pick a likely next one
So whatIt can sound right and still be wrong (hallucination)
Useful line“On the surface… underneath it is…”

M1 · Terms

Four names. Four jobs.

Separate the roles before you use them. They are not four cooler synonyms.

LLM

Large language model

A trained engine that continues text: read context, emit the next token.

Why it looks like this: scale + statistics to imitate language.
Prompt

Prompt

The context and rules you give it — it continues from your words.

Why it matters: how you ask steers which “likely” path it follows.
Agent

Agent

A setup with a goal, tools, and steps — not just one chat turn.

Why design it: multi-step work needs memory, calls, and loops.
Skills

Skills

Reusable abilities (search, calc, draw, edit files…) attached to an assistant.

Why split them: general text + special tools beat one black box.

M1 · Same ask, two versions

Same intent. Two questions.

Left is too broad. Right names the process. Compare which one you can actually check.

Vague

“How does AI work?”
  • Target too wide — almost any answer “fits”
  • No observable steps
  • Easy for the model to fill with stories

Precise

“After I send a sentence, how does an LLM predict one token at a time and stitch them into a reply?”
  • Has a start, a process, an output
  • You can follow up and verify
  • You can spot which stretch is nonsense
Habit: name the process, then ask 5 / 6
