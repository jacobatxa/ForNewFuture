From camp · What is intelligence

A simple test

Can it still get things done when the environment changes?

After Shane Legg (DeepMind) — simplified for class

Intelligence: still find a way when the world shifts.

Not “looks smart.” Not “follows one rule forever.”
Rule only · sprinkler Same schedule, rain or shine

Fires on the clock. Weather changed — behavior didn’t.

Adapts · golden retriever This door closed? Try another.

Goal stays; path changes. That gap is the start of “intelligent.”

Ask the room: who is “smarter,” and why? 3 / 10
From camp · Five abilities

Score anything with the same five

A classification tool — you set the criteria. That is abstraction practice.

01

Perceive

Notice what is happening around you.

Dog hears footsteps. Sprinkler does not “notice” rain.
02

Understand

Hold a small world model: cause → effect.

Dog knows the frisbee went over the fence.
03

Plan

When several paths exist, pick one that fits.

Delivery robot: wait, or go around?
04

Act

Change the world — not only talk about it.

Chat AI can advise; it has no hands.
05 · Key

Learn

Fail once, change next time.

Dog vs porcupine. Sprinkler never updates.

M1 · Same ask, two versions

Same intent. Two questions.

Warm-up for camp’s prompt habits — without teaching the full ladder yet.

Vague

“How does AI work?”
  • Target too wide
  • No steps to check
  • Easy to fill with stories

Precise

“After I send a sentence, how does an LLM predict one token at a time and stitch a reply?”
  • Start · process · output
  • You can follow up
  • You can spot nonsense
Habit: name the process, then ask 9 / 10
