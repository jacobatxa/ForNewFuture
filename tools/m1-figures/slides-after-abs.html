第一格 · 大模型What a model actually is

大模型 = 被训练好的「会接话的大脑」。你跟它聊天，它在猜下一个最可能的词。

豆包 / DeepSeek / ChatGPT
用小学生能懂的话，解释什么是抽象
抽象就是：丢掉差别，留下共同的那一点，再给它起个名字……
发消息给大模型…
  • 它擅长写、改、翻译、出主意、解释概念
  • 它不自带你的文件、你的日历、你的真实世界
  • 平时最常用：手机/网页里直接开聊——多数人的第一站
记住：大模型是「发动机」。没装进环境或助手里时，它主要就是聊天。

讲法

  • 屏幕上指：输入框 = 你说话；回复气泡 = 它猜出来的下一串词。
  • 追问：它知不知道你学校门口有几棵树？——不知道，除非你告诉它或联网查。

第二格 · 运行环境Runtime: where the model works on a project

运行环境 = 大模型的「车间」。它能看见文件夹、改代码、跑命令——不只是聊两句。

  • 里面仍有大模型——换模型像换发动机
  • 多出来的本事：读项目、改文件、开终端
  • 谁常用：要做网页、小程序、作业脚本的人
别叫「编程工具」——它是运行环境：大模型在这里对着真实项目干活。

讲法

  • 对比上一页：聊天窗口 vs 左边文件树。问：哪一边更像「车间」？
  • 强调：Cursor ≠ 大模型本身；Cursor 里可以选不同模型。

讲法

  • 问：如果助手「记住你过敏不能吃花生」，这算哪样本事？——记忆。
  • 预告：下一页画三者关系，再往后才拆提示词/Token。

展开 · 记忆到底是什么Memory: what it can still recall

记忆 = 它还能想起什么。分两层：写进模型里的「本事」，和写在助手里的「关于你」。

A · 模型里的记忆

参数

训练时读过海量文字，本事存成一大堆数。你关了网页，它还「会说话」——靠的是参数。

B · 助手里的记忆

关于你的记录

Personal Agent 可以记住：你的名字、科目、偏好、上次没做完的事。换一台电脑也可能还在。

偏好任务资料库
聊天区：大模型刚开聊时，知不知道你昨天吃了什么？——一般不知道。那是 B 层记忆的事。

别混

  • 参数 ≠ 聊天记录。聊天记录可以删；参数是模型本体。
  • 隐私：告诉助手的家庭住址、密码——不要。

展开 · 提示词就是输入Prompt = what you put in

今天只立一个入口：提示词 = 输入。你说不清，它就只好猜。

含糊

「帮我写作业」

清楚

「你是小学科学老师。用 80 字解释光合作用。不要超纲。结尾出一道判断题。」

第 1 步：在助手里写清角色、任务、不能做什么。说不清，它就猜。

演示边界

  • 只「指认」三处，不展开写长提示词、不装复杂 skill——留给第二节。
  • 落到 Personal Agent 货架上真用；运行环境里的提示词同理。

展开 · Token：一口一口咬字Tokens: how AI bites text

AI 不是一个字一个字读，而是一块一块读。一块叫 Token。它按块读、按块写，用 AI 也常按块收费。

切法是示意。每家不一样；中文大约一两个字一块，英文常一个词一块。

玩法

  • 按「切！」前先让孩子猜几块。
  • 回扣：训练读了约 14.8 万亿块，就是这个「块」。
