问题 2 · 解密What is really behind each picture

点一张，看它背后藏着什么。

四个都对。AI 吃两样东西：电，喂它的身体；Token，喂它的脑子。书是它上学时吃的 Token，太阳是电的老家。

提问链

  • 建议顺序：电 → 太阳 → 书 → Token。最后翻 Token，告诉孩子"这个词后面还会专门玩一次"。
  • 可以顺口提隐私：你发给 AI 的话和图片，有的公司会拿去继续训练，所以很多 AI 有"不让我的内容用于训练"的开关。

知识点要讲准

  • 电：大型 AI 机房功率常在十万千瓦以上，按一年满负荷约 8.8 亿千瓦时，够几十万户中国家庭一年的生活用电。不同机房差别很大，说"大的机房"。
  • 书：DeepSeek-V3 技术报告（2024）写着训练用了约 14.8 万亿个 Token。一个人一辈子读几千本书，也就几亿字。
  • Token 的切法每个模型不一样，屏幕上的切法只是举例。
  • 太阳：煤是远古植物存下的太阳能，风和水的流动也靠太阳晒热空气和蒸发海水。核电和地热不是来自太阳，所以说"大多"。

问题 3 · 解密What is really behind each picture

点一张，看它背后藏着什么。

AI 没有固定的样子。外壳随便换，身体是芯片，本事在数字里。热身结束。下一页进入正题：把 AI 拆成几块。

提问链

  • 建议顺序：机器人 → 芯片 → 星星 → 大脑。四张翻完，宣布热身结束，直接进入正题。
  • 翻"星星"时停一下：银河系大约有一千亿到四千亿颗星，6710 亿比它还多。

知识点要讲准

  • 芯片：一块 H100 里约有 800 亿个晶体管（就是"开关"）。训练大模型通常要几千到几万块这样的芯片，DeepSeek-V3 训练用了 2048 块。
  • 参数：6710 亿来自 DeepSeek-V3 技术报告（2024）。数字墙上的数是随手生成的示意，不是真参数。
  • "神经网络"只是借了人脑的样子，真实的人脑比它复杂得多，别说"AI 和人脑一样"。

  • 先不点，问："你会怎么分这 12 样？"收两种说法。

把抽象说出口：四句式造句游戏Say it out loud: four sentence frames

学一种新思维，就是学一种能说出口的句式。点句式 → 点词块填空 → 在聊天区再造一句自己的。

先选「归纳句」。点词块填进横线，拼出一句完整的抽象表达。

四句式（必须显性化）

  • 归纳：「它们都有___，所以归为___」
  • 命名：「我把___的共同点命名为___」
  • 边界：「凡是___都属于___；只要___，就不算___」
  • 反思：「我舍掉了___只留___；换个抽法会___」
  • 课堂：屏幕拼一句示范 → 聊天区每人再造一句（可换「出行 / 动物 / AI零件」主题）。
  • 收口：会说这四句，抽象才算内化；下一阶段用 AI 工具时，这就是你的方向盘。

第一格 · 大模型What a model actually is

大模型 = 被训练好的「会接话的大脑」。你跟它聊天，它在猜下一个最可能的词。

豆包 / DeepSeek / ChatGPT
用小学生能懂的话，解释什么是抽象
抽象就是：丢掉差别，留下共同的那一点，再给它起个名字……
发消息给大模型…
  • 它擅长写、改、翻译、出主意、解释概念
  • 它不自带你的文件、你的日历、你的真实世界
  • 平时最常用：手机/网页里直接开聊——多数人的第一站
记住：大模型是「发动机」。没装进环境或助手里时，它主要就是聊天。

讲法

  • 屏幕上指：输入框 = 你说话；回复气泡 = 它猜出来的下一串词。
  • 追问：它知不知道你学校门口有几棵树？——不知道，除非你告诉它或联网查。

第二格 · 运行环境Runtime: where the model works on a project

运行环境 = 大模型的「车间」。它能看见文件夹、改代码、跑命令——不只是聊两句。

  • 里面仍有大模型——换模型像换发动机
  • 多出来的本事：读项目、改文件、开终端
  • 谁常用：要做网页、小程序、作业脚本的人
别叫「编程工具」——它是运行环境：大模型在这里对着真实项目干活。

讲法

  • 对比上一页：聊天窗口 vs 左边文件树。问：哪一边更像「车间」？
  • 强调：Cursor ≠ 大模型本身；Cursor 里可以选不同模型。

  • 隐私：告诉助手的家庭住址、密码——不要。

展开 · Token：一口一口咬字Tokens: how AI bites text

块数 —先猜再切 · 中文常 1–2 字一块

AI 不是一个字一个字读，而是一块一块读。一块叫 Token。它按块读、按块写，用 AI 也常按块收费。

切法是示意。每家不一样；英文常一个词一块。

玩法

  • 按「切！」前先让孩子猜几块。
  • 回扣：训练读了约 14.8 万亿块，就是这个「块」。

展开 · 技能是可装卸的本事包Skills: plug-in abilities

技能（Skill）= 临时插上的本事。模型是发动机；技能是工具箱里多出来的那几件。

ENGINE 大模型 会说话 · 会写字
点右边技能槽装卸。拔掉「查日历」，模型还会不会聊天？——会。它只是少了一样本事。

收口

  • 第二节才真装一个 Skill；今天只建立「可装卸」的图景。
  • 和个人助手第三格呼应：Agent 才认真谈技能入口。
