## 2. 三个教育理念（每个模块都必须同时落地）

**H**：一节课只能讲一个概念，但三个理念要在同一节课里都出现，且**按「动手 → 追问为什么 → 逼自己讲清」的顺序**串起来，不是并列三段。

### 2.1 AI 应用（动手）
- 定义：孩子真的会用工具完成任务，并能说清"我是怎么让它干活的"。
- 证据：能用一句话把要求、限制、好坏标准说清楚；能改、能删、能核对。
- 反面（判跑偏）：教"这个按钮点哪里"、比谁的小助手更炫、把提示词当咒语背。

### 2.2 万物机理（看懂底下）
- 定义：能把看得见的界面和看不见的层级分开看，讲明白它底下怎么转。
- 证据：能画出层级/路径图；能说出"用网络"不等于"在网络里"；能指出 AI 在哪一步会编。
- 反面（判跑偏）：只背术语不画图；把"要用网"当成"属于网"；讲原理变成讲产品发布会。

### 2.3 思维（方法）
- 定义：抽象、逻辑、批判、系统、论证、表达——六个能力轴模块就是这个理念的六张脸。
- 证据：能定标准、能指出推理断点、能给出处、能画关系图、能写四段报告、能被追问。
- 反面（判跑偏）：把"批判"讲成"唱反调"；把"系统"讲成"要素清单"；不落地的空口号。

### 2.4 权重与节奏（S，可调但要有理由）

| 阶段 | AI 应用 | 万物机理 | 思维 |
|---|---|---|---|
| M1–M2 | 40% 先给成就感 | 30% | 30% |
| M3–M4 | 25% 工具退后 | 35% | 40% |
| M5–M6 | 20% 当对手盘 | 30% | 50% |

## 3. 六模块架构（H）

**两条轴必须分开，不许混。**混了就会变成"拼接感"：能力名和流程名混在一个序列里。

- **能力轴（六节，全是认知能力，可单独检验、互不重叠）**
  `抽象 → 逻辑 → 批判 → 系统 → 论证 → 表达`
- **项目轴（AI for X，贯穿全课四个里程碑）**
  `定方向 → 立论 → 查证 → 成稿与公开呈现`

**H**：模块标题只能用能力轴的名字。「选题」「研究」「成文」「讲述」是项目轴的里程碑，不许再当模块名。

AI for X 组织方式（H）：**全班按学科分小组，每组做同一道题的同一方向**（Math / Art / History，Science 可选）。同一节能力课，四组用同一套方法、各自的题目；组内共研一道题、呈现时立场必须一致；另外三组各出一个外行追问。

## 4. 单节课教案标准（H，缺一项不合稿）

每份教案必须包含：

1. **节次 / 时长 / 形式**（线上 or 线下）
2. **学完能做什么**（1–2 条，可当面验证，动词可观察）
3. **关键概念**（≤3 个）
4. **逐段流程**（分钟级；线上每 8–10 分钟换一次动作）
5. **线上互动设计**（飞书会议具体用什么：投票 / 分组讨论 / 白板拖拽 / 聊天区接龙 / 屏幕共享挑错）
6. **学生产出物**（可截图、可提交的"小物"；没交＝这节课没发生）
7. **教具与物料清单**（含备用方案）
8. **常见卡点 + 现场怎么接**（至少 3 条，来自真实课堂）
9. **验收三问**（每人 1 分钟：你做了什么 / AI 做了什么 / 你质疑过什么）
10. **给家长的一条**（课后 24 小时内：今天学了什么、孩子拿出什么、今晚可以问他一句什么）

**H**：作品可以靠 AI 生成，回答不行——所以每节课都必须以"三问"收口，答不上不算过。

## 5. 文案规范（H）

### 5.1 语感
- 一句话不超过 30 字；一段不超过 3 句。
- 主动语态、具体动作；不用"进行/作出/对于…来说"这类翻译腔句式。
- 术语第一次出现给一句话解释；同一份材料内不换叫法。

### 5.2 直译腔替换表（命中就改）

| 别写 | 改成 |
|---|---|
| 带走 / take away | 学完能拿出 / 产出 |
| 终局 / endgame | 结课看什么 |
| 走几站 / walk through | 这节课做什么 / 分几步 |
| 出口 / 出口标准 | 结课产出 / 结课标准 |
| 接住 / 接住机制 | 能用上 / 能听懂并复述 |
| 接到后面 | 为下一节准备 |
| 否掉一处说法 | 推翻一处说法 / 不采纳 |
| 赋能 / 抓手 / 闭环 / 生态 / 沉淀 / 拉通 | 换成具体动作 |
| 赢在起跑线 | 具体说孩子会做什么 |

### 5.3 三套口径
- **家长版**：只说孩子会变成什么样、能做什么，不出现教学法名词。
- **学生版**：第二人称、当次课就能做完。
- **教师 / 学校版**：可以用标准术语，但要指到具体环节与证据。

### 5.4 硬性细节
- **X**：不用 emoji；不靠感叹号堆情绪；不喊口号。
- 数字与单位统一（「18 小时」不要一处 18h、一处 18 小时）。
- 用户给的标题与文案原样使用，不改造。

## 6. 视觉与交互规范（H）

- **总体风格**：克制。正式文档黑白或深色为主、细线分隔、少色块，不要"科技感渐变紫"。
- **优先级**：能让人看懂的**可操作图** > 精美静态图 > 纯文字说明。
- **交互图的做法（"物体即解释"）**：不要画方框、箭头、标签；为一个原理**发明一台真实的机器**，它的运转本身就是那个概念。尺寸分档：Figure 40–80 个零件（约 1 小时）、Hero 80–150（2–4 小时）、Epic 6 小时以上（不擅自开工）。方法全文与示例见 `~/tools/anatomy/SKILL.md`。
- **交付形态**：单文件 HTML、零外部依赖、零 CDN，双击能开；手机 390 宽不横向溢出；体积 ≤5MB；`prefers-reduced-motion` 下静止；键盘可操作。
- **长图 / 海报**：竖版 420 宽为基准，3 倍导出（1260 宽）；卡片式装框（编号 + 短标题 + 提示 + 读数）；图里不放长文字。
- **PDF**：Chrome headless `--no-pdf-header-footer --print-to-pdf`，出完看页数与留白再交付。

---

## 7. 事实与合规红线（H）

- **不许编造**：学校名、师资、升学结果、合作方、价格、数据一律不编；缺就留空并标"待确认"。
- **不许承诺升学**：不写"进名校""拿奖"这类结果承诺。
- **未成年人保护**：不满 14 周岁属儿童，注册与个人信息处理需监护人同意；班级统一用家长手机号 + 班级邮箱。
- **不做陪伴类智能体**：《人工智能拟人化互动服务管理暂行办法》（2026-07-15 施行）对未成年人有专门限制，课程里只做任务型助手，不做虚拟伴侣、不做陪聊。
- **素材留档**：图片必须可追溯来源；孩子正脸不使用或需家长书面同意；教材原文不进入任何对外材料。
- **引用标准要注明年份与版本**（如「2025 年版」），不写"最新标准"。

| 术语 | 定义 | 别叫 |

## 10. 改动流程（H）

| 层级 | 谁能改 | 需要什么 |
|---|---|---|
| 文案层（措辞、标题、替换用词） | 任何 agent | 改完在提交说明里写「只改文案，未动结构」 |
| 单课教案层（流程、分钟数、教具、产出） | agent 可以提，需人确认 | 提交说明写清改了哪几分钟、为什么 |
| 模块架构层（六个模块的名字与顺序、总课时、线上/线下比例、AI for X 组织方式） | **只有人决定** | agent 只出方案与影响分析，不动主文件 |

- 每次改完跑一遍第 11 节自检。
- 涉及对外材料（宣传、招生页）的改动，额外跑一遍"数字与単位一致性"检查。
