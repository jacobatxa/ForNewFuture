# 中文教育文案：去直译腔

## 常见直译腔 → 中文说法
| 直译腔 | 问题 | 改后 |
|---|---|---|
| 带走 / take away | 名词化，生硬 | 学完能拿出 / 产出 |
| 终局 / endgame | 游戏词 | 结课看什么 / 最后留下什么 |
| 走几站 / walk through stops | 路线比喻直译 | 这节课做什么 / 分几步 |
| 出口 / 出口标准 | exit 直译 | 结课产出 / 结课标准 |
| 接住 / 接住机制 | catch 直译 | 能用上 / 能听懂并复述 |
| 接到后面 | 直译 | 为下一节准备 |
| 人判断、模型起草 | 语序生硬 | 模型先起草，人来判断 |
| 否掉一处说法 | 术语感 | 推翻一处说法 / 不采纳 |
| 赋能 / 抓手 / 闭环 / 生态 | 公文腔 | 换成具体动作 |
| 赢在起跑线 | 广告腔 | 具体说孩子会做什么 |

## 教研黑话 → 说人话（对外材料、家长版、学生版一律换）
用户原话：「我听不懂你在说啥呢」——出现听不懂就是文案失败，不是用户不懂行。目标：家长一眼懂，老师能当场验证。

| 黑话 | 问题 | 说人话版 |
|---|---|---|
| 结构图 / 抽象层级 | 听不出要干什么 | 能把它拆开讲清楚：由哪几块组成、每块管什么 |
| 说清简化了什么、丢了什么 | 教研内部口径 | 能说出这张图里省掉了什么、为什么可以省 |
| 要素—关系—反馈回路 | 系统论术语 | 能说出“这事动了这里、那里会跟着变”；画一张谁影响谁、哪里会反噬的图 |
| 可检验目标 / 表现性任务 / 量规 | 教学设计术语 | （删掉）直接写“学完能做什么”，并加一句“怎么当场看出来他会不会” |
| 认知负荷 / 迁移 / 检索练习 | 学术词 | 一页只讲一个概念；换个场景再用一次；讲完就让他复述，不许翻笔记 |
| 命题卡 / 研究四格 | 内部产物名 | 一张卡片：我要查什么、拿什么当证据、什么能让我改口 |

自检：把每条“学完能做什么”念给一个没参与课程设计的家长听，他需要反问一句以上就重写。动词必须可观察（能说出、能指出、能画、能推翻）。

## 三套口径（同一门课，三种写法）
- **家长版**：只说孩子会变成什么样、能做什么，不出现教学法名词
- **学生版**：第二人称、具体动作、当次课就能做完
- **教师/学校版**：可以用标准术语，但要指到具体环节与证据

## 交付前替换检查（grep）
对外材料（家长版/学生版/海报/推文）拦截：
`带走|终局|出口|接住|接到后面|赋能|抓手|闭环|生态|沉淀|打法|颗粒度|拉通|对齐|结构图|抽象层级|要素|反馈回路|量规|认知负荷|迁移|检索练习`
命中就改，除非是引号内引用或教师版内部文档。

## 其他硬规则
- 不用 emoji；不靠感叹号堆情绪
- 一句话不超 30 字；一段不超 3 句
- 术语首次出现给一句话解释，同一材料内不换叫法
- 数字与单位统一（不要一处 18h、一处 18 小时）
- 用户给的标题/文案原样用，不改造
