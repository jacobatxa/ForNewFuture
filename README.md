# 彼灯教育 · 课程归档

AI 课程库：https://jacobatxa.github.io/ForNewFuture/

> **任何 agent 或协作者动手前，先读 [`framework/00-课程设计大纲.md`](framework/00-课程设计大纲.md)。**
> 它写明硬约束（H）、软建议（S）、禁区（X）、术语表、文案与视觉规范、交付自检清单。
> 不读就产出，大概率会写成"另一门课"。

三门课按子项目分开放。本地 `git pull` 之后打开对应文件夹即可。

| 文件夹 | 是什么 |
|---|---|
| `wulingshan/` | 武陵山五日营。`course/` 是课件（目前 Day 1），`promo/` 是宣传长图 |
| `camp/` | 创想营。`course/` 是国庆那套四步课；`promo/2026-11-baicao/` 是百草湖这一期宣传 |
| `literacy/` | AI 通识初阶（周末 18 小时）。`course/` 里是大纲和 M1 课件 |
| `salon/` | 家长场沙龙 |
| `framework/` | 教育理念与施工规范，不属于某一门课。**先读 `00-课程设计大纲.md`**，再看 `01-教育框架.md` |
| `framework/skills/` | **给 agent 用的技能库**：教案设计 / 交互可视化 / 中文文案 / 标准对齐，含各家 agent 的安装方法 |

根目录留下的旧文件名只做跳转，例如原来的 `16-m1-deck.html` 会转到 `literacy/course/16-m1-deck.html`。
