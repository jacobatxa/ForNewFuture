核心共同点
01

学校要把孩子从「解题的人」变成「解决问题的人」。学习由真实问题来驱动，而不是死板训练。

02

留出更多时间让孩子接触真实世界：看世界怎么运转，参与企业正在发生的事，而不是坐在教室里看电子屏。

03

知识传授和考试都没有取消。只是更早用现实结果来检验学得怎么样，而不是等到毕业后再从企业初级工做起。

04

这几所学校都在强调同一件事：基础知识原理（教材里的问题）、社会与商业如何运转、独立思考和当众表达、动手把想法做成（ideas into practice）。

Conundrum 是学校自己出的开放题：没有标准答案，要你站队，并讲清为什么。申请时任选一道，交视频或音频。下面三道最常被提起。

Chocolate Conundrum

员工找到了公司巧克力的秘密配方。自己开店，能不能用？

Astra Sweets 靠一种别人不知道的配方成为最好吃的巧克力。配方是员工 Nova 发现的。她要开 Nova Sweets，能不能把这个配方带走？

A 不能 · Team Astra Sweets B 能 · Team Nova Sweets
NASA Conundrum

航天局有七个项目，钱只够做三个。你砍掉哪四个？

选三个，等于公开你的优先级：眼前的地球、人类的安全、还是更远的未知。

A 载人上火星 B 机器人探未知世界 C 太空旅游 D 挡小行星 E 最强太空望远镜 F 把地球研究清楚 G 每个学校都上行星科学
Moonshot Conundrum

一个国家想集中花钱，把生活变好。钱该优先给谁？

它不想撒胡椒面，想把大部分钱压在少数目标上，好更快看见进展。没有标准配比，要能讲清取舍。

A 探索 · 太空、深海、微观 B 教育 · 孩子爱去的学校 C 环境 · 动植物与空气水源 D 把人连起来 · 城市、路、网络 E 新想法 · 科研、技术与艺术

听什么听的是推理过程，不是背到了哪一个「正确」选项。社团是课外活动；这里的课余是九十门可选的真课。

02
读数

牛津整体 16.5%，不等于中国学生也是 16.5%。

中国大陆是牛津最大的海外申请来源。挤在这条赛道上的人最多，通知没有按人数同比例增加。不是歧视，是中国学生之间的竞争更密。剑桥口径更严：成功率 = 入学人数 ÷ 申请人数。名额有限，申请池最密的那群人，通道最窄。

牛津怎么读

  • 整体通知比例 16.5%
  • 中国大陆 10.3%，不是同一回事
  • 中国是最大海外申请来源

剑桥怎么读

  • 成功率 = 入学 ÷ 申请
  • 2025 轮次中国 9.8%
  • 海外申请里中国占 34.9%

听什么

  • 不是「牛津歧视」
  • 是中国学生之间更密
  • 申请池最密，通道最窄

同一条主线，两档难度。启航班把抽象落到身体和故事；创造营用真工具、真用户。可压成 3–5 天营，也可按周末展开。金标是启航班，蓝标是创造营。

单元一 · 懂 AI · 3 课时
  • 01初识智能：自然智能 vs 人工智能启乌鸦喝水、人脸识别；分类大挑战；图灵小游戏创智能谱系；下文预测机；中文房间辩论产出：四格漫画 30 秒讲 / 一页智能地图 + 立场声明
  • 02大模型边界：第一行 prompt，把模型问倒启藏头诗；问倒大赛；查证三问随身卡创幻觉是流畅不是真实；提示词阶梯；10 题边界评测产出：防骗三问卡 / 模型边界评测报告
  • 03工具生态与第一个私人 Agent启助手说明书；教师投屏生成；小组互测创模型层→应用层→Agent；系统提示词 + 工具 + 记忆产出：可演示 Agent v1 / 可运行 Agent + 工程文档
单元二 · 会思考 · 2 课时
  • 04真问题从哪来：有人群、有频次、有痛感启烦恼收集箱；采访同桌；全班票选创双钻；同理心地图；校园田野调查；伪需求解剖产出：问题卡 / 问题定义文档 v1
  • 05逻辑学与产品闭环：主张—证据—反例启四个生活化谬误找茬；因为所以；解决闭环草图创十个高频谬误；质疑委员会压力测试；闭环图冻结产出：任务书 + 闭环草图 / 问题定义 v2 + 蓝图
单元三 · 造产品 · 7 课时 · RPS Real Problem Solution
  • 06–07初级：最小可用原型，能给人试用启A3 纸面原型；模板化可点 demo；跨组用户测试创AI 编程工作流；范围切割；结对编程 + Bug 榜产出：MVP + 3 条用户意见 / 可运行 MVP + README
  • 08–09进阶：插件、多模态、用户系统启能力卡牌选购（10 金币取舍）；3 分钟路演预演创API 与多模态接入；最小用户系统；5 分钟 Pitch 答辩产出：路演版 + 讲稿 / 路演级产品 + 现场答辩
  • 10–12高阶：存储、托管、运营、AI 安全启不告诉 AI 的秘密；家人试用 3 条反馈；毕业展摆摊创上线投放 20–50 人；运营漏斗；安全红队；终期路演产出：发布版 + 反馈报告 / 上线产品 + 看板 + 安全自查

启航班 · 约 10 岁 · 具象

三条铁律：多用身体少用屏幕；AI 永远在教师眼皮底下；每课带走可看见的产出。

评价看说清楚、做出来、改得动、防得住。不看术语，不看界面漂不漂亮。

创造营 · 初二 · 形式运算

三条原则：真工具、真代码、真用户；幻觉按概率生成理解；没有「学完」，只有「做出来」。

评价看机制理解、逻辑硬度、工程完整、真实责任。Cursor 类工具，真实部署。

共同底线：问题必须真实、产出必须可见、AI 产出必须经人核验。难度可在类比 / 机制 / 论文三档里调，允许跳级，不允许跳过。

03 · 课程 B · 青年创始人社区

真实问题里的同伴与责任

不是又一门编程课。把通识里练到的判断，放进有客户、有截止日期、有当面反馈的协作场。

真问题

从生活与社区里选可验证的麻烦，而不是选题作文。先有人群、频次、痛感，再动手。伪需求当场拆掉。

同伴 / 导师

跨年龄协作。成人是教练与提问者，不是代写。围桌争对错。逻辑树画在墙上，讲不清就还没想清。

路演与迭代

叙事是痛点 → 演示 → 证据 → 愿景。向真人演示，收集拒绝与修改。有截止日期，判断仍是自己的。

上线与安全

能拿起来的东西：链接、模具、反馈报告。密码、家庭住址、身份证号绝不告诉 AI。责任留在人，不留给模型。

现场还会碰到：交换思想、白板表达、企业级工具、电脑创作、3D 打印真实模具。选题、原型、用户、路演，都在这间房子里发生。
